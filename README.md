# 🛡️ Insurance Analytics Dashboard | Power BI

## 📊 Project Overview

This project is an interactive **Insurance Analytics Dashboard** developed using Microsoft Power BI.

The dashboard provides a consolidated view of business performance by analyzing meetings, invoices, opportunities, revenue, employees, and opportunity stages.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Cleaning
- Data Transformation
- Data Visualization

## 📈 Dashboard Features

The dashboard provides analysis of:

- Account Executive-wise Meeting Performance
- Account Executive-wise Invoice Analysis
- Opportunity Stage-wise Revenue
- Product Group-wise Opportunity Analysis
- Top Open Opportunities
- Employee-wise Analysis
- Year-wise Analysis
- Revenue and Opportunity Performance

## 🔍 Key Analysis

The dashboard helps analyze:

- Meeting activity by account executives
- Invoice distribution across account executives
- Revenue generated across opportunity stages
- Product group performance
- Top open opportunities based on revenue
- Employee-level performance
- Business trends using interactive filters

## 🎯 Project Objective

The objective of this project is to transform insurance business data into an interactive Power BI dashboard that provides meaningful insights into sales activities, opportunities, revenue, and employee performance.
